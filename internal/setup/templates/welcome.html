Welcome to zoom-notifier Setup

This wizard will help you configure zoom-notifier. You'll need:

  • A Zoom developer account with a webhook-only app configured
  • Slack workspace admin access to install the Slack app
  • The public URL where this server will be accessible

Enter the public URL where this server is accessible (e.g. https://zoom.example.com).

How do I know my server URL?

This is the URL that Zoom and Slack will use to reach your server. It must be publicly accessible from the internet. If you're running behind a reverse proxy or load balancer, use the external URL (not localhost). For example: https://zoom.example.com.
