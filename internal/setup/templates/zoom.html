Zoom Configuration

Connect zoom-notifier to your Zoom account so it can receive meeting events (started, ended, participant joined/left).

Which Zoom app type do I need?

Create a Server-to-Server OAuth app. This single app handles both webhook event notifications and API access for meeting links. You only need one Zoom app.

Step-by-step: Create a Server-to-Server OAuth app in Zoom
  1. Go to the Zoom App Marketplace — Build App page and sign in.
  2. Choose Server-to-Server OAuth as the app type and click Create.
  3. Give it a name (e.g. "zoom-notifier") and click Create.
  4. On the App Credentials tab, note your Account ID, Client ID, and Client Secret. You’ll need the Account ID below; the Client ID and Secret can be configured later for meeting links.
  5. Go to the Information tab. Fill in the required fields (company name, developer name and email) and click Continue.
  6. Go to the Feature tab. Toggle Event Subscriptions to on.
  7. Click + Add New Event Subscription:
    • Enter a Subscription Name (e.g. "Meeting Events").
    • Set the Event Notification Endpoint URL to the webhook URL shown below.
    • Click + Add Events and select these under Meeting:
      • Start Meeting
      • End Meeting
      • Participant/Host Joined the Meeting
      • Participant/Host Left the Meeting
  8. Copy the Secret Token from the Feature tab (above the Event Subscriptions section) and paste it below.
  9. Click Save Secret below so the wizard can respond to Zoom's validation challenge.
  10. Back in Zoom, click Validate to verify the endpoint. It should succeed now.
  11. Click Save in Zoom.
  12. Go to the Scopes tab. Click + Add Scopes, search for "meeting", and add meeting:read:admin. This enables fetching meeting join links.
  13. Go to the Activation tab and click Activate your app.
  14. Come back here and click Next.
Your webhook endpoint:
{{.Data.ServerURL}}/webhook/zoom

Paste this URL into the Event Notification Endpoint field in your Zoom app.

Where is the Secret Token?

In your Zoom Server-to-Server OAuth app, go to the Feature tab. The Secret Token is displayed near the top, above the Event Subscriptions section. This is not the same as the Client Secret — it’s used specifically for webhook CRC validation.

Where is the Account ID?

In your Zoom Server-to-Server OAuth app, go to the App Credentials tab. The Account ID is shown at the top, alongside the Client ID and Client Secret. This is used to link incoming Zoom events to your workspace.

Save the secret first so Zoom's Validate button will work. Then click Next to continue.
