Configure the Zoom webhook integration. You'll need a webhook secret from your Zoom app.

Where do I find this?
  1. Go to the Zoom App Marketplace and sign in.
  2. Navigate to Develop → Build App.
  3. Select or create a Webhook Only app.
  4. Under Feature, find the Secret Token field.
  5. Copy the token and paste it here.
