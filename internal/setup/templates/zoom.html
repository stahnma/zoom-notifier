Zoom Configuration

Connect zoom-notifier to your Zoom account so it can receive meeting events (started, ended, participant joined/left).

Which Zoom app type do I need?

You need a Webhook Only app. This is the simplest app type — it just sends event notifications to your server. You do not need a General App or a Server-to-Server OAuth app for basic notifications.

A Server-to-Server OAuth app is only needed if you want meeting links with passcodes in notifications. You can add that later in Advanced settings.

Step-by-step: Create a Webhook Only app in Zoom
  1. Go to the Zoom App Marketplace — Build App page and sign in with your Zoom account.
  2. Choose Webhook Only as the app type and give it a name (e.g. "zoom-notifier").
  3. Fill out the required basic information fields (company name, developer contact) and click Continue.
  4. On the Feature page, toggle Event Subscriptions to on.
  5. Click + Add Event Subscription, then:
    • Set the Event Notification Endpoint URL to the webhook URL shown below.
    • Click + Add Events and select these under Meeting:
      • Start Meeting
      • End Meeting
      • Participant/Host Joined the Meeting
      • Participant/Host Left the Meeting
  6. Copy the Secret Token from the Feature page and paste it below.
  7. Click Save Secret below so the wizard can respond to Zoom's validation challenge.
  8. Back in Zoom, click Validate to verify the endpoint. It should succeed now.
  9. Click Save in Zoom, then come back here and click Next.
Your webhook endpoint:
{{.Data.ServerURL}}/webhook/zoom

Paste this URL into the Event Notification Endpoint field in your Zoom app.

Where is the Secret Token?

In your Zoom Webhook Only app, go to the Feature page. The Secret Token is displayed near the top, above the Event Subscriptions section. This token is used to validate that webhook requests are genuinely from Zoom.

Save the secret first so Zoom's Validate button will work. Then click Next to continue.
