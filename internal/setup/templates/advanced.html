Zoom API Credentials (optional — enables meeting links with passcodes)

These credentials come from a separate Server-to-Server OAuth app in the Zoom Marketplace. If you skip this, notifications will still work but won't include clickable meeting links. The Account ID from the Zoom step is reused automatically.

How do I create a Server-to-Server OAuth app?
  1. Go to the Zoom App Marketplace — Build App page.
  2. Choose Server-to-Server OAuth as the app type.
  3. Give it a name (e.g. "zoom-notifier API access").
  4. On the app info page, copy the Client ID and Client Secret.
  5. Fill out the required basic information and continue to Scopes.
  6. Add these scopes: meeting:read:meeting:admin and meeting:read:invitation:admin.
  7. Activate the app.
